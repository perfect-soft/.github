## Perfect Soft — makers of Perfect Streamer®

**Perfect Streamer** is an IPTV / OTT streaming server for broadcast-grade delivery of TV channels over the public Internet
and IP networks: SRT, RIST, Pro-MPEG FEC, UDP/RTP multicast, HLS / DASH, MPTS multiplexing, a TR 101 290 analyzer, DVB input,
transcoding (NVIDIA NVENC, Intel VPL, CPU), and the proprietary Perfect Stream (PS1) protocol for reliable point-to-point
delivery.
